# 📦 API de Pedidos

API REST para gerenciamento de um sistema de pedidos, desenvolvida com Java 21 e Spring Boot.

O objetivo da aplicação é fornecer uma base completa para controle de usuários, produtos e pedidos, seguindo boas práticas de desenvolvimento backend e arquitetura em camadas.

## 🚀 Funcionalidades (em evolução)

### 👤 Usuários *(em breve)*

* Cadastro de usuários
* Busca por ID e e-mail
* Listagem de usuários
* Atualização de dados
* Remoção de usuários

### 📦 Produtos *(em breve)*

* Cadastro de produtos
* Listagem de produtos
* Atualização de informações
* Remoção de produtos

### 🧾 Pedidos *(em breve)*

* Criação de pedidos
* Associação de usuários e produtos
* Listagem de pedidos
* Atualização de status

## 🧱 Arquitetura

A aplicação segue uma arquitetura em camadas:

* **Controller** → exposição dos endpoints REST
* **Service** → regras de negócio
* **Repository** → acesso aos dados
* **Entity** → modelo de domínio
* **DTO** → transporte de dados entre camadas

## 🛠️ Tecnologias

* Java 21
* Spring Boot
* Spring Data JPA
* Maven

## 📌 Objetivo

Este projeto tem como objetivo evoluir para uma API completa de pedidos, servindo como base para estudo de:

* Arquitetura de software
* Boas práticas com Spring
* Padrões de projeto
* Construção de APIs REST escaláveis
